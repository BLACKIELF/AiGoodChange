# AiGoodChange 使用说明

当前源码基于 `1.0.0`，包含尚未发布的新功能。原名 QuickToggle（轻唤）；历史安装包仍保留旧名称与功能。
仓库：https://github.com/BLACKIELF/AiGoodChange
历史下载：[轻唤 1.0.0](https://github.com/BLACKIELF/AiGoodChange/releases/tag/v1.0.0)。

AiGoodChange 只做一件事：给常用 App 一组**全局快捷键**。按一下呼出，再按一次安全隐藏或回到刚才的前台。它是原生 macOS 菜单栏程序，没有账号。可检查 GitHub 正式发行版，不会自动下载或安装。

## 主界面

`⌘F` 搜索应用或快捷键；“待设置”找到尚未配置的应用；“占用记录”管理需要避开的组合。应用行继续支持呼出／恢复、改键、自动打开、说明和移除，并显示注册状态。

右下角“设置与帮助”管理登录启动、辅助功能和快捷键参考；展开帮助不会压缩主列表。操作反馈固定显示在窗口底部。变化见 [更新日志](../CHANGELOG.md)，历史版本见 [1.0 说明](releases/1.0.md)。

## 1. 安装

1. 历史安装包可下载 [轻唤 1.0.0](https://github.com/BLACKIELF/AiGoodChange/releases/tag/v1.0.0) 的 macOS arm64 ZIP，或从源码构建。
2. 在仓库根目录执行下面的命令。构建使用 ad-hoc 签名，或复用本机已有开发证书；没有 Apple 公证。
3. 首次打开若被拦截：系统设置 → 隐私与安全性 → 仍要打开。
4. 菜单栏出现火焰图标表示 AiGoodChange 在运行。AiGoodChange 退出后，全局快捷键会失效。

```bash
bash build.sh --release
open "build/AiGoodChange.app"
```

需要 Apple Silicon、macOS 13+ 和 Xcode Command Line Tools。验证和打包使用独立目录：

```bash
bash selfcheck.sh
bash package.sh
```

分别输出到 `build/checks/` 和 `build/package/`。可用 `QUICKTOGGLE_BUILD_DIR` 指定其他目录。

## 2. 打开与查找

- 默认 `⌘3` 显示或隐藏主窗口，可在标题旁更改。
- 菜单栏 → 打开 AiGoodChange，或重新打开 App，也会显示主窗口。
- `⌘F` 搜索，`⌘N` 添加应用，`⌘W` 关闭当前窗口；关闭主窗口后菜单栏程序仍继续运行。
- “全部应用”按快捷键排序，“待设置”只显示未配置组合的应用，“占用记录”独立显示本机需要避开的组合。
- “设置与帮助”管理登录启动、权限和可展开的快捷键参考；面板可以滚动，主列表尺寸保持不变。

## 3. 添加应用并录制快捷键

1. 点「添加应用…」，从已安装可视应用里选，或从磁盘挑 `.app`；选定添加后会尝试自动分配可用快捷键。
2. 若 `⌘1–9` 还有空闲组合，添加后 AiGoodChange 会自动分配下一个（自动跳过「本机已占用」列表和设置窗口快捷键 `⌘3`）；`⌘` 数字用尽后会尝试 `fn/🌐1–9、0`。Fn 通道需要辅助功能授权，首次选择时若尚未授权，完成系统提示后重新录制即可。
3. 点该行右侧录制按钮，按下组合键。
4. Esc 取消；Delete / Backspace 清除。
5. 保存后立即生效。

访达也在选择器中：搜索“访达”并添加，再点该行“未设置”录制快捷键。访达首次添加不自动分配组合。

更换 App：点击行左侧的图标或名称，选择另一个应用，原快捷键与未运行时打开设置保留。行尾“更多”菜单提供呼出／恢复、自动打开、快捷键说明和移除。

**每次录制都会自检：**

1. 应用还在不在
2. 是不是已经被 AiGoodChange 里别的应用占用
3. 是不是在「本机已占用」列表里（新安装为空表；旧配置会保留已有记录，可在“占用记录”中移除或添加）
4. 普通组合由 Carbon 检查能否独占注册；`fn/🌐 + 数字` 检查事件 tap 能否建立并监听

空闲才会改键。占用则保留原快捷键，状态栏写「已探测：占用」。

## 4. 两次按键怎么走

快捷键绑定的是应用。AiGoodChange 负责呼出或收回对应应用；同一应用里的多个具体窗口，仍使用该应用或 macOS 的窗口操作来选择。

| 当时状态 | 第一次 | 第二次 |
|---|---|---|
| 目标已隐藏 | 呼出 | 再藏回去 |
| 目标已在前台 | 安全隐藏，不关窗口 | — |
| 窗口全最小化 | 有辅助功能时只恢复一个窗口 | 只把这个窗口再最小化 |
| 目标已显示但不在前台 | 激活 | 隐藏并尽量回到刚才的前台 |

刚呼出立刻再按一次，也会隐藏。若你已经手动切到别的 App、目标重启、或窗口已被藏起，这次会重新呼出，不会把按键吞掉。

一次物理按压只会触发一次：长按产生的键盘重复、或按键抖动不会误当成“第二次”；松开组合键后可立即再按。目标启动/重开若已超时或被后续操作替代，迟到的旧回调也不会覆盖当前会话。

## 5. 快捷键规则

- 优先：未占用的 `⌘0–9`
- `⌘` 数字用尽后：`fn/🌐0–9`（需辅助功能授权）
- 也可用：`⌘⌥K`、`⌘⇧K`、`⌃⇧K`、`⌘⌥←/→`、`⌃⇧F1–F12`
- 字母 / 方向键 / F 键：至少两个修饰键，且必须包含 Command 或 Control
- `fn/🌐 + Q`、Fn 方向键等已知系统组合会被拦住；`fn/🌐 + F1–F12` 会受“将 F1、F2 等键用作标准功能键”及外接键盘固件影响，本版不注册
- 单按 Globe 若配置为切换输入法、显示表情与符号或开始听写，Fn 数字会提示可能不可达或同时触发系统行为
- 每个应用必须用不同组合
- 「本机已占用」同样覆盖 Fn 组合；但 macOS 无法暴露所有系统动作、应用非独占快捷键或键盘固件映射，Fn 组合会明确保留风险提示

## 6. 权限与登录

- **辅助功能**：Carbon 快捷键默认不用；精确恢复某个最小化窗口或使用 `fn/🌐 + 数字` 时，点「授权恢复与 fn…」申请。明确录制 Fn 组合也会触发系统授权提示。
- **登录时启动**：默认关。打开后由 macOS 登录项启动 AiGoodChange，不另加 LaunchAgent。开机后要快捷键继续可用，打开这个开关。

## 7. 配置导出与导入

- **导出**：菜单栏 → 导出配置…，生成 `quicktoggle-backup-日期.json`。内容含全部应用绑定、设置快捷键、启用状态和「本机已占用」列表。
- **导入**：菜单栏 → 导入配置…，选此前的备份文件，确认后整体替换当前配置。备份里本机没装的应用会自动跳过，并在状态里点名。
- **换机流程**：旧机导出 → 拷贝 JSON → 新机导入。纯本地文件，不联网。
- 更名沿用 `com.quicktoggle.app` 和原配置键，既有快捷键继续保留；内部可执行文件、备份文件名和构建变量沿用 QuickToggle 命名。
- 窗口底部可选择 AiGoodBro 的 10 套主题，随系统使用深浅色；主题选择独立保存，不包含在上述 JSON 中。

## 8. 休眠与更新

- 设置与帮助中可“检查更新…”，也可关闭默认开启的“每天自动检查一次”。发现更新后打开 GitHub 发行页，由用户自行下载；不会自动下载或覆盖安装。

- 唤醒、解锁、点菜单栏、打开设置时，会强制重新注册全部快捷键。
- 磁盘上的 App 比正在跑的进程新时，会自动重启换成新包。
- 菜单栏“状态与版本”中有只读的「AiGoodChange 版本 (build N)」和诊断摘要；摘要会显示应用数、已注册热键数、Fn 事件通道状态及辅助功能权限，排查“某个键没生效”时可先核对这里。
- 快捷键录制中若切到其他窗口会自动取消；VoiceOver 会读出当前是录制中还是已设置的组合。

## 9. 隐私

不上传应用列表或快捷键，无遥测、无账号。更新检查仅请求 GitHub 公开发行信息。应用列表、快捷键、主题和配置备份保存在本机。源码采用 MIT License，主题随包保留 AiGoodBro 上游许可。
